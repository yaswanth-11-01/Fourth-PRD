---> Student Daily Expense Tracker

---> Project Explanation

Student Daily Expense Tracker is a Java console-based application used to track a student's daily expenses based on a fixed budget. The program takes the student's name, daily budget, and different expenses such as food, travel, study, and other expenses. It calculates the total expense and checks whether the student is within the budget, has fully used the budget, or has exceeded the budget. Finally, it displays a complete expense report.
